# BMC4 — pack client

Pack du serveur Minecraft **BMC4**, en Better MC Forge 1.20.1.

## Installation

1. Télécharge le zip depuis la [dernière release](../../releases/latest)
2. CurseForge → Minecraft → **Créer** → **Importer** → le fichier zip
3. Dans les paramètres de l'instance : **Java 17** et **8 Go de RAM**
4. Lance **l'instance BMC4**, pas le launcher Minecraft habituel

## Le serveur

Adresse : **bmc4.mine.fun**

431 mods, huit dimensions, deux factions.

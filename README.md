# BMC4 — pack client et documentation

Serveur Minecraft français en factions, Better MC BMC4, Forge 1.20.1.

```
bmc4.mine.fun
```

## Installation

1. Télécharge le zip depuis la [dernière release](../../releases/latest)
2. CurseForge → Minecraft → **Créer** → **Importer** → le fichier zip
3. Paramètres de l'instance : **Java 17** et **6 à 8 Go de RAM** — en
   allouer davantage dégrade les performances
4. Lance **l'instance BMC4**, pas le launcher Minecraft habituel

## Ce dépôt

```
releases/      le pack client, par version
guides/        ce que couvrent les guides du Discord
reglements/    règles, système de raid, mémo modération
config/        les configurations modifiées et pourquoi
decisions.md   le journal des décisions du serveur
```

`config/README.md` est le fichier à rouvrir après chaque mise à jour du
pack : il liste tout ce qui a été changé par rapport à l'original, et que
la mise à jour écrase.

`decisions.md` explique **pourquoi** chaque choix a été fait. C'est ce qui
se perd le plus vite.

## Le serveur

431 mods, huit dimensions prégénérées, deux factions.

Sauvegarde toutes les heures sur 48 heures, redémarrage quotidien à 5 h,
difficulté normale.

# Les guides

Écrits pour ce serveur, à partir des fichiers du serveur et de la
documentation des mods. Publiés dans la catégorie GUIDE du Discord.

## Principe de rédaction

**Ne rien inventer.** Chaque valeur chiffrée vient soit d'un fichier de
configuration du serveur, soit d'une source vérifiée. Quand ce n'est pas
vérifiable, le guide le dit.

**Les fichiers du serveur priment sur les wikis.** Ils donnent les valeurs
de notre version, et révèlent les réglages personnalisés qu'aucun wiki ne
mentionne.

**Renvoyer vers le guide en jeu quand il existe.** Le carnet de quêtes FTB
et les livres de mods sont meilleurs que n'importe quelle reformulation.

## Erreur à ne pas refaire

Trois guides ont été écrits pour des mods **absents du pack** — Occultism,
Ars Nouveau, Sophisticated Backpacks — parce qu'ils ont été rédigés de
mémoire sans vérifier `/mods`.

**Toujours vérifier la présence du mod et lire sa configuration avant
d'écrire.**

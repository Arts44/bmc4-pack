# 🎬 Cinematic Interactions — travailler de vos mains

Les blocs de travail deviennent des **scènes à la première personne** : vous posez les objets sur l'établi, vous chargez le four à la main, vous forgez à l'enclume.

## 🧰 Les stations

```
Fabrication  établi, four, fumoir, haut-fourneau
Outils       enclume, meule, table de forgeron, tailleur
Magie        table d'enchantement, alambic
Déco         métier à tisser, table de cartographie
Lecture      lutrin, bibliothèque ciselée, juke-box
Repos        feu de camp, feu des âmes, balise
```

Les coffres, tonneaux et boîtes de shulker gardent leur fenêtre normale.

## 🎮 Les commandes

```
Clic droit   entrer dans la scène
^            s'asseoir devant un feu de camp
*            maintenir : vue orbitale pendant une scène
Échap        sortir de la scène
```

Votre touche d'inventaire ou une touche de déplacement font aussi sortir.

Dans la scène, choisissez un objet dans le panneau d'inventaire, puis cliquez sur les zones en surbrillance.

💡 **Vous avez repris vos réglages avec le script de migration ?** Ces deux touches sont alors **H** et **Alt gauche**. Vous pouvez les changer dans **Options → Contrôles… → Assignation des touches…**

## ⚠️ L'établi n'est pas un coffre

**Un objet posé sur un établi peut être pris par n'importe qui, même dans un claim. Reprenez vos objets en partant.**

C'est aussi vrai pour la grille de l'établi avec Visual Workbench.

Tout le reste suit les règles habituelles : dans le claim d'une autre faction, fours, alambics et juke-box restent fermés, sauf alliés et raid entre vos deux factions.

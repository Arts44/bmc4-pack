# v66 — BROUILLON, incomplet : les autres mods de la v66 restent à écrire

## Ce qui arrive

- **Cinematic Interactions** : les blocs de travail deviennent des scènes à la
  première personne. On pose les objets sur l'établi, on charge le four à la
  main, on forge à l'enclume. Le mod vient d'un fork BMC4 d'une version bêta
  (corrections pour les claims) : signale tout ce qui te semble cassé.

## ⚠️ L'établi n'est pas un coffre

**Un objet posé sur un établi peut être pris par n'importe qui, même dans un
claim. Reprends tes objets en partant.** C'est aussi vrai pour la grille de
l'établi avec Visual Workbench.

## Les touches

Sur une nouvelle installation : **^** pour t'asseoir au feu de camp, **\*** pour
la vue orbitale pendant une scène. Si tu as repris tes réglages avec le script de
migration, ce sont **H** et **Alt gauche** ; tu peux les changer dans **Options →
Contrôles… → Assignation des touches…**

## Si le mod est retiré un jour

Les objets posés sur un établi restent dans le fichier `cinematic_tables.dat` et
deviennent invisibles. **Avant un retrait annoncé, vide tes établis.**

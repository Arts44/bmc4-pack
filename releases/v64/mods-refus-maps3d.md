# Message pour #mods — refus de Maps 3D (v64)

À poster par Arthur. Texte prêt à coller :

---

**Maps 3D : refusé, pour une raison technique.**

Merci pour la proposition. Maps 3D affiche les autres joueurs sur la carte.
Sur BMC4, la carte ne montre jamais les joueurs : le mode fair-play de Xaero
coupe le radar pour tout le monde, et le règlement interdit les radars de
joueurs. Le mod n'a pas d'option que le serveur puisse imposer pour masquer
les joueurs : on ne peut donc pas l'ajouter sans redonner à chacun la position
des autres, à travers les murs, avant un raid.

Si une autre carte 3D sans affichage des joueurs vous tente, proposez-la ici :
on la regardera à la prochaine revue.

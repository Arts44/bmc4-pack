# v62 — 6 octobre 2026

**Deux mods ajoutés, invisibles en jeu.** Tout le monde doit réimporter le
pack : le serveur refuse les connexions dont la liste de mods diffère.

## Installation

1. Télécharge le zip de cette release
2. CurseForge → **Minecraft → Créer → Importer** → choisis le zip
3. Paramètres de l'instance : **Java 17** et **6 à 8 Go de RAM**
4. Lance l'instance BMC4, pas le launcher Minecraft habituel

⚠️ **Réimporte plutôt que de bricoler l'ancienne instance.** Ajouter les
jars à la main marche jusqu'au jour où il en manque un, et le message
d'erreur de Forge n'aide personne.

## Ce qui arrive

### ⚙️ KubeJS 2001.6.5-build.26 et Rhino 2001.2.3-build.10

Rien à voir ni à régler : ces deux mods font tourner, côté serveur, des
règles que le pack ne savait pas exprimer seul. Ils doivent pourtant être
présents chez chacun : KubeJS déclare des entrées que le serveur et le
client doivent partager à la connexion. Rhino est le moteur JavaScript
dont KubeJS a besoin.

Au premier lancement, un dossier `kubejs/` apparaît dans l'instance, avec
deux scripts d'exemple qui n'écrivent qu'une ligne dans le journal. On n'y
touche pas.

## Ce qui change sans se voir

- Les deux jars sont ceux du serveur, à l'octet près : ils sont dans le
  zip, pas téléchargés par CurseForge à l'import.

## Pour les curieux

ces deux mods n'ont pas pu rester sur le serveur seul.
